# Task Management

スプレッドシート風のタスク一覧・1日のタイムブロック・ポモドーロタイマーを1画面にまとめた個人用アプリ。
データはブラウザの IndexedDB に保存される（サーバー不要）。

## 起動

```bash
pnpm install
pnpm dev
```

http://localhost:5173 を開く。

## 使い方

### タスク一覧
- セルをクリックして選択、文字を打つとそのまま編集（日本語入力OK）
- `Enter` で確定して下へ、`Tab` / `Shift+Tab` で左右へ、矢印キーで移動
- タスク名の最終行で `Enter` すると新しい行が追加される
- `Backspace` / `Delete` でセルを空にする
- 「時間」型の列は `1h30m` / `1.5h` / `90`（分）/ `90分` / `1時間30分` / `1:30` のどれでも入力できる
- Google Sheets などからコピーした範囲を貼り付けると、選択セルを起点に取り込む（行が足りなければ追加）
- 「フィルタ」で選択肢の列（Project・Status など）を絞り込み（複数選択可）。フィルタ中に追加した行にはその値が入る
- 「並び替え」でタスク名・各列・作成日の昇順／降順。条件は複数追加でき、上の条件が同じものを下の条件で並べる
  （例：Project → Status で、Project ごとに未着手→進行中→完了）。選択肢の列は選択肢の並び順で並ぶ
- フィルタ・並び替え・完了を隠すは次回も残る
- 列見出しのメニューから並び替え・名前変更・選択肢の編集・列の削除、右端の `+` で列を追加
- 列見出しの右端をドラッグすると列幅を変更（ダブルクリックで標準の幅に戻す）。幅は次回も残る
- 間違えて作った選択肢は「選択肢を編集」（列見出しのメニュー、または選択肢セルの一番下）で直す。
  名前を変えるだけで直せるほか、正しい選択肢と同じ名前にすると1つにまとまり、削除するとタスクから外れる
- 選択肢の「完了扱い」にチェックした値（初期状態では Status の「完了」）のタスクは完了として表示される

### カレンダー（Google カレンダー風）
- 「カレンダー」タブで週表示／日表示を切り替え
- 空き枠をクリックすると1時間、ドラッグすると選んだ範囲で枠を作り、作成済みのタスクを検索して選ぶ
  （タスク自体は左の「タスクを追加」か一覧画面で作る）
- 予定はドラッグで移動（別の日にも移せる）、下端をドラッグで長さを変更
- 予定をクリックすると詳細。タイトル変更・完了にする・ポモドーロ開始・予定を削除
- 左のタスク一覧（未割り当て／予定済み）からカレンダーへドラッグしても予定にできる

### ポモドーロ
- 作業が終わると通知と音で知らせる
- 歯車ボタンで時間や自動開始を設定
- タブのタイトルに残り時間が出る
